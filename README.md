# 🎮 discipline farming rpg

Un proyecto experimental para convertir el desarrollo de hábitos en una experiencia estilo RPG.

> ⚠️ **Estado:** Beta / Proyecto de entrenamiento.

## 📖 Descripción

Este proyecto nace como una práctica para mejorar mis habilidades con React mientras experimento con una idea que quiero desarrollar en el futuro.

La aplicación busca representar al usuario como un personaje de un RPG, donde cada hábito es una habilidad que puede subir de nivel mediante la constancia.

## 🚧 Estado del proyecto

Actualmente este proyecto es una **beta** y un espacio de experimentación.

Es posible que dentro de unas semanas o un mes vuelva a empezar el proyecto desde cero con una mejor arquitectura.

## 🎯 Objetivos

- Practicar React.
- Mejorar la organización de componentes.
- Diseñar una interfaz inspirada en videojuegos RPG.
- Experimentar con mecánicas de progresión y estadísticas.
- Definir la base de una futura aplicación más completa.

## 💡 Idea principal

Cada hábito será una habilidad.

Ejemplos:

- ⚔️ Disciplina
- 📚 Lectura
- 💪 Ejercicio
- 🧠 Estudio
- 😴 Sueño
- 🥗 Alimentación
